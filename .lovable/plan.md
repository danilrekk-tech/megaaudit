# AI-аудит сайтов — веб-сервис с клиентским и служебным режимами

Сервис в стиле megagroup.shop: светлая технологичная палитра, аккуратная типографика, карточки с мягкими тенями, бейджи категорий и статусов. База из 118 доработок (8 категорий) загружается из приложенного файла.

## Клиентская часть

**Главная (/)**
- Поле ввода адреса сайта + три пресета для теста: интернет-магазин, корпоративный сайт, лендинг.
- Короткое объяснение, что даёт аудит.

**Сканирование (/audit/$id)**
- Анимация последовательной проверки пяти зон: удобство заказа и корзины, мобильная адаптивность, доверие и контакты, скорость и вовлечение, SEO и коммерческие факторы.
- Затем отчёт: общий скор удобства и конверсии, оценки по зонам, сильные стороны, узкие места.
- Блок влияния на бизнес: потерянные заявки, брошенные корзины, отток мобильных — в понятных цифрах и процентах.
- Рекомендации: подобранные доработки с названием, выгодой для бизнеса, ссылкой на страницу услуги и на демо.
- Кнопка «Сформировать КП» — печатная версия предложения (печать/сохранение в PDF через диалог печати).

## Служебный режим

- Малозаметная ссылка в футере, вход по PIN-коду. Доступ хранится в браузере.
- **Журнал аудитов**: все проверки с датой, сайтом, скором, типом сайта; фильтры и поиск.
- **Карточка аудита**: служебные заметки, комментарий для менеджера, вероятность апсейла, технические детали.
- **Конструктор КП**: выбор доработок из базы, цены, скидка, этапы внедрения, итоговая смета и печать.
- **База доработок**: поиск, фильтр по категориям, добавление, редактирование, архивирование, привязка к типам проблем (зонам аудита).
- **Повторный аудит**: сравнение двух проверок одного сайта — что улучшилось, что осталось.

## Алгоритм аудита

Детерминированный (одинаковый результат для одного адреса): по адресу и признакам определяется тип сайта — магазин, услуги или лендинг — затем формируются оценки зон, находки и подбор доработок по привязке «проблема → категория/услуга». Одинаковые данные при повторном открытии отчёта.

## Техническая часть

- TanStack Start, маршруты: `/`, `/audit/$id`, `/staff`, `/staff/audits/$id`, `/staff/catalog`, `/staff/proposal`.
- База доработок как модуль-сид (импорт JSON) + слой хранения в localStorage для правок; аудиты и КП тоже в localStorage. Бэкенд не подключаем — данные живут в браузере.
- Отдельная тема: акцентные фирменные цвета и токены в `src/styles.css`, все цвета семантические.
- Печать КП через CSS `@media print`, без внешних библиотек PDF.
- SEO: свой `head()` на каждом клиентском маршруте, служебные страницы `noindex`.

## Что стоит учесть

- Цены доработок в файле отсутствуют — в конструкторе КП они задаются вручную, по умолчанию пустые.
- Аудит оценивает сайт по алгоритму сервиса, не загружая внешние страницы: реальные внешние проверки скорости и вёрстки можно добавить позже отдельным шагом.
